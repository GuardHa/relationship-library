# 从认识到相处

**一本可以直接阅读、分享给同学的恋爱与沟通学习手册。**

十章正文、原创情境对话、综合案例、四周练习计划和复盘表。全书约 1.3 万字，按学习顺序编排，适合先通读再练习。

## 开始阅读

- **[在线阅读全文](book/从认识到相处.md)**：手机或电脑直接打开。
- **[PDF 阅读版](book/从认识到相处.pdf)**：有封面、目录和页码，可下载后发给同学。

## 本书怎么学

| 顺序 | 主题 | 你将练习什么 |
| --- | --- | --- |
| 01 | 先弄清自己想要什么 | 区分偏好、需要与底线 |
| 02 | 让别人认识真实的你 | 用具体经历介绍自己 |
| 03 | 从共同情境开始聊天 | 开场、接话和自然结束 |
| 04 | 聊天节奏是共同形成的 | 区分事实与猜测，确认安排 |
| 05 | 先听懂，再决定怎样帮忙 | 倾听、复述和确认需要 |
| 06 | 提出一个容易理解的邀请 | 具体邀约、改期和接受拒绝 |
| 07 | 把边界说清楚 | 表达限度、确认同意与保护隐私 |
| 08 | 把争吵变成可以讨论的问题 | 描述事件、提出请求和修复 |
| 09 | 长期关系需要共同安排 | 协商时间、付出与未来计划 |
| 10 | 面对分手与复合 | 停止纠缠、处理事务与复盘 |

建议每次读一章，完成一个练习。可与愿意参与的同学轮流扮演原创案例中的角色；无需分享真实私人聊天。

## 内容从哪里来

这是一份基于本地关系资料的**选择性改写、评析和原创练习手册**。章末说明保留与不采纳的观点，书末列出来源文件和页码／时间戳。它没有把原作者的个案、数字、性别概括或技巧效果当作已经证实的结论。

公开书中不包含私人聊天截图、身份信息、小说正文或露骨内容。原始资料库不随本仓库分发。书中的示例均为原创虚构情境。

## 配套 Codex 技能

技能位于 `.agents/skills/relationship-library`。用 Codex 打开本仓库后，可以说：

> 用 $relationship-library，结合这本书的第八章，帮我把这段表达改成更清楚的沟通。

技能可直接查阅仓库内的公开书稿，无需原始私人资料库。

```sh
python .agents/skills/relationship-library/scripts/read_book.py --query "冲突 请求"
python .agents/skills/relationship-library/scripts/read_book.py --chapter "第七章"
```

### 可选的个人资料检索

如需检索自己的更多 Markdown 资料，可在本地 `data/` 目录放置 `文档/唯一标识/标题.md` 和 `完整清单.json`，再运行 `library.py build`。`data/` 已被 Git 忽略；不需要此功能的读者可以直接读书。

清单是 JSON 数组，每项包含 `source`（来源名称）、`output`（相对 data 的文档路径）、`status`、`characters`（实际正文字符数）和可选的 `notes`。使用 Python 3.10 或更新版本，无需外部 API 密钥。索引与总集仅在本地生成。

GitHub 提供书稿和程序的访问；它不是已经部署好的在线问答服务。手机可以直接阅读书稿和 PDF，运行技能则需要可执行该技能的环境。
