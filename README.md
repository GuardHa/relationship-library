# 亲密关系实践手册

**按“心理理解 → 交往原则 → 具体方法 → 案例拆解”组织的成人学习手册。**

新版正文约 2.7 万字，PDF 54 页，21 章，5 组完整案例，涵盖恋爱、短期约会，以及 SM／BDSM 的角色、边界与照顾协商。每个主题结合解释、可改写的表达、不同回应下的选择与练习。

## 资料与依据

这是一份基于本地关系资料的**选择性改写、评析和原创学习手册**。书末列出本地议题线索及公开研究、同意教育和健康资料；心理研究概括注明了摘要依据与局限，不把群体差异套成个人说明书，也不把关联当作效果保证。

原始资料库不随本仓库分发，公开书中没有私人聊天截图、身份信息、小说正文或露骨内容。案例均为原创虚构情境。

## 配套技能

技能位于 `.agents/skills/relationship-library`，可以直接检索两本公开书稿，不依赖私人资料库。使用支持此类技能的环境时，可以请求：

> 用 $relationship-library，参考《亲密关系实践手册》第九章，帮我把自己的约会意图说清楚，并演练对方想认真恋爱时怎么回应。

或：

> 参考第二十章，用一个虚构的成年人物案例，带我练习角色与边界协商，只练沟通。

从仓库根目录运行：

```sh
python .agents/skills/relationship-library/scripts/read_book.py --book practice --chapter "第二十章"
python .agents/skills/relationship-library/scripts/read_book.py --query "意图 邀约"
python .agents/skills/relationship-library/scripts/read_book.py --book basic --chapter "第八章"
```

`practice` 为新版，`basic` 为基础版；默认搜索两本书。结果附书名、章节、路径及行号。程序使用 Python 3.10 或更新版本，不需要外部 API 密钥。

### 可选的个人资料检索

如需检索自己的更多 Markdown 资料，可在本地 `data/` 目录放置 `文档/唯一标识/标题.md` 和 `完整清单.json`，再运行 `library.py build`。清单为 JSON 数组，每项包含 `source`、`output`（相对 data 的文档路径）、`status`、`characters` 和可选的 `notes`。`data/` 已被 Git 忽略，索引与总集在本地生成。

GitHub 提供书稿与程序的访问，尚未部署在线问答服务。手机可以直接读书与下载 PDF；运行技能需要支持执行该技能的环境。
